Question: Can I put my secret key in frontend environment variables?

No. Do not put a secret key in frontend environment variables: frontend values can be exposed in the browser, and secret keys must never be placed in a browser or shipped application. Use a secret key only in a secure, developer-controlled component instead. (57a134af9256e047477b) For clarity about RLS: a secret key bypasses RLS when the request carries no user access token. If it carries a signed-in user's access token, the request runs under that user's RLS policies, even if the client was initialized with a secret key. (3c1260041656e577e619)

Question: My browser query returns an empty array. Could this be a permissions issue?

An empty array does not necessarily mean the request has a permissions problem. A missing table grant raises a permission error before Row Level Security (RLS) is evaluated; a policy that matches no rows can instead return an empty result. Please check whether the request returns an error and verify the table grants for the role used by your browser request before investigating the RLS policy. The available information does not establish the cause of your empty result.
